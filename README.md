# 💼 Job Tracker

Uma página de busca de vagas de emprego, especialmente em tecnologia. O site coleta informações das APIs do Google Jobs e do Remotive, retornando as vagas que contém as palvaras-chave pré-definidas. É possível utilizar o campo de busca para procurar por um cargo, local ou empresa específicos. O foco do projeto foi a usabilidade e o consumo de APIs.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **React**
* **TypeScript**
* **Axios**
* **Vercel**

---

## ⚙️ Como executar o projeto localmente

Se desejar testar o projeto na sua máquina:

1.  Clone este repositório:
    ```bash
    git clone [https://github.com/guilermes/job-tracker.git](https://github.com/guilermes/job-tracker.git)
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
